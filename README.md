• git init / git clone: Inicia um repositório do zero na sua pasta ou baixa um projeto existente do GitHub.
• git status: Mostra quais arquivos foram modificados ou criados antes de você salvá-los.
• git add .: Adiciona todas as alterações feitas na pasta para a fila de espera do salvamento.
• git commit -m "mensagem": Salva permanentemente as alterações na sua máquina com uma nota explicativa.
• git push: Envia os seus salvamentos locais direto para o repositório online no GitHub.
• git pull: Baixa as últimas atualizações do GitHub para o seu computador para manter o código em dia.
• git checkout -b nome: Cria e entra em uma ramificação separada para testar códigos sem estragar o projeto principal.
• git merge nome: Junta as alterações e novidades de outra ramificação com a branch onde você está.
